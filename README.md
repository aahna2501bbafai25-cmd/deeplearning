# Deep Learning – Fashion Image Classification

## 📌 Overview

This Google Colab practical introduces **Deep Learning** and **Artificial Neural Networks (ANNs)** through a fashion product image classification problem.

The business scenario is based on an **e-commerce company receiving thousands of product images**. Instead of manually identifying every product, a Deep Learning model can help classify images into different product categories.

The practical focuses on understanding the steps involved in building, training, testing, and using a simple neural network for image classification.

---

## 🎯 Learning Objectives

By completing this practical, students will be able to:

* Understand how images can be used as input for Deep Learning.
* Build a simple Artificial Neural Network.
* Understand input, hidden, and output layers.
* Train a model on product images.
* Check model accuracy.
* Use a trained model to predict a product category.
* Connect Deep Learning output with a business use case.

---

## 🏪 Business Scenario

An e-commerce company receives a large number of product images every day.

### Current Process

```text
Product Image
      ↓
Employee Manually Identifies Category
      ↓
Product Added to Website
```

### AI-Assisted Process

```text
Product Image
      ↓
Deep Learning Model
      ↓
Predicted Product Category
      ↓
Employee Reviews Result if Required
      ↓
Product Added to Website
```

The model is designed to assist with product categorization and reduce repetitive manual work.

---

## 📊 Dataset

The practical uses the **Fashion MNIST** dataset.

The dataset contains images of common fashion products such as shirts, shoes, bags, and dresses. It downloads automatically, so no manual dataset upload is required.
